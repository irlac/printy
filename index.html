    ❓ How it works

    Talks to the Phomemo M110 over Web Bluetooth (service 0xff00, write 0xff02, notify 0xff03). Every design is composed on a 768px canvas, downsampled to the head's native 384 dots, packed 1-bit MSB-first, and streamed with the M110's ESC/POS-ish command set. QR via an embedded encoder, barcodes via an embedded JsBarcode — no network needed for those. Chaos mode pulls live jokes, advice, dog photos and procedural plotter art, then a director picks the next format with comedic timing.

    🧾 Print queue

    Stack images and PDFs into one strip. Each image (or PDF page) prints whole as one package, with an automatic line break between packages — the printer's own feed lands in the break, never inside an image.
